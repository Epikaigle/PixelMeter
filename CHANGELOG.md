## 新增

- 新增应用主题设置，可在跟随系统壁纸的动态取色和自定义固定取色之间切换。
- 新增固定主题色选择，并支持在暗黑模式下启用 AMOLED 纯黑背景。

## 修复

- 修复“沉浸模式下隐藏”仅在状态栏和导航栏同时隐藏时才生效的问题，现在前台应用隐藏任一系统栏时都会自动隐藏悬浮窗。

## 优化

- 语言配置改为由 Gradle 根据资源目录自动生成，减少手写 `localeConfig` 与实际语言资源不一致的风险。

### New

- Added app theme settings, allowing you to switch between wallpaper-based dynamic colors and a custom fixed theme color.
- Added fixed theme color selection, with support for AMOLED pure black backgrounds in dark mode.

### Fixes

- Fixed “Hide in Immersive Mode” only taking effect when both the status bar and navigation bar were hidden. The floating window now hides automatically when the foreground app hides either system bar.

### Improvements

- Locale configuration is now generated by Gradle from resource directories, reducing the risk of a manually written `localeConfig` getting out of sync with actual language resources.
